# 第一阶段计划

本阶段是 1965 年越南战争大战略地图原型：63 个设计区域、可缩放拖动轮廓地图、区域详情、暂停/1/2/4 倍速和每日日期结算。

## 已完成

- 设计区域数据从工作区已有公开轮廓聚合为 63 个区域，数据明确标注“不代表1965年历史行政边界”。
- GDScript 负责模拟与绘制，JSON 负责区域数据；暂不加入战斗、完整经济或事件系统。
- Godot 4.7.2 headless 解析与运行检查待本阶段结束时确认；Windows 导出沿用现有配置并在确认后记录证据。

## 取舍记录

`godot-grand-strategy-map` 的思路适合参考地图节点/镜头交互，但本原型采用 Godot 自带 `draw_colored_polygon`，避免引入第三方插件和 P 社素材；轮廓来源为仓库既有 `vietnam-provinces-game.json`，由脚本转换为本项目数据。
