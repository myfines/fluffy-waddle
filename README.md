# Vietnam War 1965 · Godot 治理原型

这是一个 Godot 4.7.2 的越南战争大战略地图原型，开局日期为 1965-01-01。地图完整采用 710 个细分设计区域；这些区域由工作区已有轮廓数据转换而来，仅用于游戏抽象，不代表 1965 年历史行政边界。玩家固定扮演南方执政者，北方只作为外部压力。

运行：在本目录执行 `..\GodotPortable_4.7.2\Godot_v4.7.2-stable_win64.exe --path .`，或双击 `builds\VietnamWar1965-governance.exe`。若需重新导出 Windows 版本，执行 `powershell -ExecutionPolicy Bypass -File tools\build_windows.ps1`。

操作：开局默认选中一个南方地区，按右侧“三步引导”即可上手；左键选区并查看阵营/地形/叛乱/支持/治安；空格暂停或继续；1、2、4 设置速度；滚轮缩放；中键拖动；M民生、S治安、P地方谈判；F/H/I切换阵营、民心、叛乱填色模式；“聚焦南方治理区”把镜头移到主要治理区域；Esc 退出。日期按模拟时间逐日推进，每周结算预算与政治资本，第28天触发双选事件。待决事件会暂停模拟，资源不足时选择不会被偷偷当成拒绝；军方支持或稳定度过低会倒台，稳定度达标并维持20周则成功。

政变演示入口位于右侧“政变战局 · 全国部队”。平时可选择政府部队并点击目的地区调动；政变开始后全国部队先冻结，玩家只能调动反政变方，政变方由简单 AI 通过同一权限命令调集，中立部队不可动。右侧会显示双方进度、10支部队归属和三个控制点的实际地区名（首都、电台、军营）；反政变方获胜后部队解冻并归政府调度，政变方获胜则本局失败。

南北分类采用游戏简化规则：地区中心纬度 `>= 17°N` 视为北方外压，其余视为南方可治理。这是为了保证原型中的治理边界稳定，不能当作历史行政边界或历史精确复原。

数据与模拟分离：`data/design_regions.json` 是区域数据，`scripts/main.gd` 负责绘制、交互和日期推进。未加入战斗、完整经济、外交或事件系统。

开源仓库提供 `data/demo_regions.json` 作为许可明确的10区演示输入，干净 clone 后可以直接运行。当前工作区若存在本地 `data/frontier_regions.json`，程序会优先加载完整710区版本；该轮廓及 `data/vietnam_*.json` 的上游许可尚未确认，因此不会随公开仓库发布。需要完整地图时，请把自有或已获授权的同 schema 数据导入为 `data/frontier_regions.json`，并确认 `regionCount` 为710。

地图实现使用 Godot 自带绘制 API，地图被放在裁剪视口内，支持阵营/民心/叛乱填色和图例；几何在加载期缓存，镜头变换不重复清理/投影/三角化。原始轮廓文件与旧版 710 地区构建保留在工作区，不是本轮启动入口。
